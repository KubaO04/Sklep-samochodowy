# IG Motors — sklep samochodowy

Pliki strony znajdują się w [ig-motors/public/index.html](ig-motors/public/index.html). Blog i formularz wymagają uruchomienia serwera lub otwarcia opublikowanej witryny.

Można otworzyć ją bezpośrednio w przeglądarce. Uruchomienie lokalnego serwera i informacje o edycji: [ig-motors/README.md](ig-motors/README.md).

Metadane pomocniczego repozytorium Sites są zachowane w ignorowanym folderze `.tools/ig-motors.git`, aby nadrzędne repozytorium mogło śledzić wszystkie pliki strony. Przed ponownym użyciem pomocnika synchronizacji Sites przenieś te metadane z powrotem do `ig-motors/.git`.
